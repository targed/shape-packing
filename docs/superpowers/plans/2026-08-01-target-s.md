# Target S Funneling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enforce `target-s` funneling in the Rust solver based on the known Friedman best_score so the loop does not start optimization runs from excessively large containers.

**Architecture:** We will implement an `inverse_friedman_metric` in Python to convert the Friedman metric back to a circumradius ($S$), pass it via `--target-s` to the Rust solver, and use it in Rust to shrink the initial starting container (`dynamic_s`) and abort stuck runs early.

**Tech Stack:** Python 3, Rust (clap)

## Global Constraints

- Python code must be formatted cleanly and use standard library imports where possible.
- Rust changes must compile with `cargo build --release` without warnings.
- The `inverse_friedman_metric` must perfectly invert `compute_friedman_metric`.

```python
def inverse_friedman_metric(f_metric: float, inner_token: str, container_token: str) -> float:
    """
    Given a target Friedman metric, compute the corresponding solver S (circumradius).
    """
    container_upper = container_token.strip().upper()
    inner_upper = inner_token.strip().upper()
    
    # Get inner scale
    if inner_upper in ("CIRCLE", "CIR", "TAN", "DOMINO", "L"):
        i_scale = 1.0
    else:
        try:
            nsi = int(inner_upper)
            i_scale = 2 * math.sin(math.pi / nsi)
        except ValueError:
            i_scale = 2 * math.sin(math.pi / 3)

    c_metric = f_metric * i_scale

    # Reverse container metric
    if container_upper in ("CIRCLE", "CIR", "TAN", "DOMINO", "L"):
        return c_metric
    else:
        try:
            nsc = int(container_upper)
            return c_metric / (2 * math.sin(math.pi / nsc))
        except ValueError:
            return c_metric / (2 * math.sin(math.pi / 3))
```
