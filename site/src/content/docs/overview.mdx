# Shape Packing System Overview

The **Shape Packing Auto-Researcher** is an autonomous search and verification framework designed to find optimal containers for packing multiple identical geometric shapes (triangles, squares, pentagons, hexagons, octagons, dominoes, L-trominoes, tans, and circles).

## Core Capabilities

- **Autonomous Search Loop:** Executes parallel numerical optimization and basinhopping solvers.
- **Dual-Engine Solvers:** High-performance Rust backend combined with Python fallback engine.
- **Mathematical Verification:** Rigorous overlap detection and containment boundary validation (`verify_solution.py`).
- **Friedman Reference Integration:** Automated parsing and verification against Erich Friedman's packing benchmarks.

## Repository Structure

- `src/shape_packing/`: Python auto-researcher orchestrator, ranking logic, and problem definitions.
- `packer_rs/`: Rust-compiled native PyO3 solver extension and CLI binary.
- `data/`: Official benchmark references (`packingVerification/`), analysis reports, and Friedman website archive.
- `scripts/`: Data ingestion, verification, log analysis, site data builder, and `autoresearch/` prototypes.
- `site/`: Astro static dashboard deployed to GitHub Pages.
